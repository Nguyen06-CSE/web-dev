Câu 8c. Technically, an ________is the collection of start tag, its attributes, an end tag and everything in between. On the other hand an HTML tag (either opening or closing) is used to mark the start or end of an element.

A. HTML attribute

B. HTML tag

C. HTML document

D. HTML element

Đáp án: D (Phần tử HTML bao gồm thẻ mở, các thuộc tính, thẻ đóng và nội dung nằm giữa).

Câu 8d. Indicate whether each of these filenames is not an acceptable name for a web document.

A. Sunflower.html

B. index.htm

C. Song_Lyrics.html

D. cooking home page.html

Đáp án: D (Tên file web chứa khoảng trắng/dấu cách   có thể gây ra lỗi đường dẫn URL khi lưu trữ trên máy chủ).

Câu 8e. One of the following markup examples is incorrect. Which one?

A. <img src = "birthday.jpg">

B. <em>Congratulations!<em>

C. <a href="file.html">linked text</a>

D. <p>This is a new paragraph</p>

Đáp án: B (Thiếu dấu gạch chéo / ở thẻ đóng </em>).
