## 🚀 Hướng dẫn chạy thử nghiệm

### 1. Chạy trên terminal với Node.js
```bash
# Chạy bài tập 2a (mã nguồn lý thuyết)
node "bài tập 15/bai-tap-2a.js"

# Chạy bài tập 2b (kiểm tra typeof)
node "bài tập 15/bai-tap-2b.js"
```

### 2. Mở trực tiếp trên Trình duyệt web
- Mở tệp `index.html` bằng trình duyệt (Chrome, Safari, Firefox,...).
- Mở Developer Tools (`F12` hoặc `Cmd + Option + I` trên macOS) -> tab **Console** để quan sát log.
