Câu 7a: A static web page (sometimes called a flat page or a stationary page) is a web page that is delivered to the user's web browser exactly as stored, in contrast to __________ which are generated by a web application.

A. dynamic web pages

B. web root

C. Internet

D. database

Đáp án: A (Trang web tĩnh đối lập với trang web động - dynamic web pages).

Câu 7b: Một phần tử HTML (thông thường) gồm các thành phần sau:

A. thẻ mở, thẻ đóng

B. thẻ mở, nội dung

C. thẻ mở, nội dung, thẻ đóng

D. thẻ đóng, nội dung

Đáp án: C (Ví dụ: <p>Nội dung</p> gồm thẻ mở <p>, nội dung văn bản và thẻ đóng </p>).

Câu 7c: Cấu trúc cơ bản của một tài liệu HTML gồm:  

A. Phần khai báo (doctype), phần tử html, phần tử head, phần tử title, phần tử body  

B. Phần khai báo (doctype), phần tử html, phần tử header, phần tử title, phần tử body

C. Phần khai báo (doctype), phần tử html, phần tử head, phần tử link, phần tử body

D. Phần khai báo (doctype), phần tử html, phần tử p, phần tử title, phần tử body

Đáp án: A

Câu 7d: Phát biểu nào sau đây là hợp lý:

A. HTML tạo ra cấu trúc và ngữ nghĩa cho phần nội dung trang web

B. HTML thực hiện việc trang trí cho trang web

C. HTML xử lý các tương tác của người dùng trên giao diện web

D. HTML vừa tạo ra phần nội dung vừa thực hiện trang trí cho trang web

Đáp án: A (CSS đảm nhận việc trang trí, JavaScript xử lý tương tác, còn HTML định nghĩa cấu trúc và ngữ nghĩa).

Câu 7e: Phát biểu nào đúng khi nói về “”?

A. Là một thẻ HTML

B. Là một khai báo trong tài liệu HTML

C. Là một phần tử HTML

D. Là một chú thích trong HTML

Đáp án: B (<!DOCTYPE html> là lời khai báo chuẩn với trình duyệt về phiên bản HTML5, không phải là một thẻ/phần tử HTML).
