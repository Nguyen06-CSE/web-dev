## Câu 11a
**Các loại phần mềm dùng để viết mã trong làm web gồm?**

A. Text editor, Microsoft Word, IDE, Web browser  
B. Text editor, Code editor, Web browser, Acrobat  
C. Mspaint, Web browser, Code editor, IDE  
D. Web browser, Text editor, Code editor, IDE  

**Đáp án: D. Web browser, Text editor, Code editor, IDE**

> Trong các phương án, D là hợp lý nhất. Thực tế Web browser không dùng để viết mã mà dùng để chạy và kiểm thử sản phẩm web; các công cụ chính để viết mã là Text editor, Code editor và IDE.

## Câu 11b
**Phát biểu nào sau đây là đúng?**

A. IDE thường có dung lượng lớn hơn code editor  
B. Không thể dịch mã chương trình bằng IDE  
C. Tất cả IDE đều là phần mềm có phí  
D. VS Code là một IDE  

**Đáp án: A. IDE thường có dung lượng lớn hơn code editor**

> IDE thường tích hợp nhiều thành phần như trình soạn thảo, công cụ build, debugger nên thường nặng hơn code editor. VS Code bản chất là code editor, dù có thể cài extension để hoạt động gần giống IDE.

## Câu 11c
**______ is the software that is designed specifically to help developers in coding. These are actually the text editors with some additional functionalities to manage and edit code.**

A. Debugger  
B. Text editor  
C. Code editor  
D. IDE  

**Đáp án: C. Code editor**

> Code editor là trình soạn thảo được thiết kế riêng cho lập trình, có thêm các chức năng hỗ trợ quản lý và chỉnh sửa mã nguồn.

## Câu 11d
**_____ is a software application that provides comprehensive facilities to computer programmers for software development. An _____ normally consists of at least a source code editor, build automation tools and a debugger.**

A. IDE  
B. Code editor  
C. Debugger  
D. Compiler  

**Đáp án: A. IDE**

> IDE (Integrated Development Environment) là môi trường phát triển tích hợp, thường gồm trình soạn thảo mã, công cụ build tự động và debugger.

## Câu 11e
**Trong các phần mềm lập trình, IntelliSense là gì?**

A. Là thành phần bổ sung của công ty Intel  
B. Là thành phần dịch mã lệnh  
C. Là chương trình gỡ lỗi  
D. Là thành phần đưa ra các mô tả ngắn hoặc gợi ý khi viết mã nguồn  

**Đáp án: D. Là thành phần đưa ra các mô tả ngắn hoặc gợi ý khi viết mã nguồn**

> IntelliSense hỗ trợ gợi ý mã, tự động hoàn thành, hiển thị tài liệu ngắn và thông tin về hàm/biến khi lập trình.
