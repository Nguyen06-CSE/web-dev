### Câu 1. Bạn có thể lập trình (viết mã) JavaScript bằng các công cụ sau. Đáp án nào sai?

- A. Web browser
- B. Text editor
- C. Code editor, IDE
- **D. JavaScript Interpreter**

**Đáp án: D**

**Giải thích:** Để viết mã JavaScript, bạn có thể dùng trình duyệt web (Web browser) với các công cụ dev tools, trình soạn thảo văn bản (Text editor) hoặc các môi trường phát triển tích hợp (Code editor, IDE). **JavaScript Interpreter** (trình thông dịch JavaScript) là công cụ dùng để **thực thi** mã JavaScript, không phải để viết mã.

### Câu 2. Trong HTML, mã JavaScript được đặt trong phần tử nào?

- A. `<javascript>`
- **B. `<script>`**
- C. `<js>`
- D. `<scripting>`

**Đáp án: B**

**Giải thích:** Trong HTML, mã JavaScript được nhúng vào trang thông qua phần tử `<script>`. Đây là phần tử chuẩn để chứa hoặc liên kết đến mã JavaScript.

### Câu 3. Trong JavaScript, ES8 là viết tắt của?

- A. Essential 8
- **B. ECMAScript 8**
- C. Explorer Source 8
- D. European Script 8

**Đáp án: B**

**Giải thích:** ES8 là viết tắt của **ECMAScript 8** (còn được gọi là ECMAScript 2017). Đây là phiên bản thứ 8 của tiêu chuẩn ECMAScript – ngôn ngữ cơ sở của JavaScript.

### Câu 4. JavaScript was created in …… by Brendan Eich, an employee of Netscape.

- A. 1994
- **B. 1995**
- C. 1996
- D. 2015

**Đáp án: B**

**Giải thích:** JavaScript được Brendan Eich tạo ra vào năm **1995** khi ông đang làm việc tại Netscape. Ngôn ngữ này nhanh chóng xuất hiện trong Netscape Navigator 2.0 vào tháng 9 năm 1995.
